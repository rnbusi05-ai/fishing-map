# バス釣りショアスポットマップ

おかっぱり（岸釣り）のスポットを湖ごとに地図にまとめたもの。iPhone のホーム画面に追加して使う。

## ファイル
| ファイル | 中身 |
|---|---|
| `index.html` | 地図（Leaflet + OpenStreetMap） |
| `data/lakes.json` | 湖の一覧（地図上部の切り替えに出る） |
| `data/<湖>.csv` | スポットのデータ（湖ごとに1ファイル） |
| `kml/<湖>.kml` | Googleマイマップ取り込み用（CSV から自動生成） |
| `tools/build_kml.py` | CSV → KML を作る |
| `tools/check_data.py` | 全スポットに情報元URL・確認日があるか確認。確認日から3か月以上たったものを一覧表示 |

## CSV の書き方
- 見出し：`名前,緯度,経度,足場,駐車場,トイレ,最寄りバス停,注意,情報元URL,確認日,確かさ`
- 分からない項目は空欄（地図では「未確認」と表示）。推測で埋めない
- 情報元URLが複数あるときは `|` でつなぐ
- 確認日は `2026-10-05` の形
- 確かさは `公式で確認` / `釣りブログなど1件` / `複数で一致` のどれか

## ピンの色
- 赤：注意欄に何か書いてある（立入禁止・釣り禁止・ボート店の敷地など）
- 緑：公式で確認、または複数の情報元で一致
- 黄：情報元が1件だけ

## 湖を追加するとき
1. `data/<id>.csv` を同じ見出しで作る
2. `data/lakes.json` に1行足す（`id`・名前・CSVの場所・地図の中心・ズーム）
3. `python3 tools/check_data.py` → `python3 tools/build_kml.py`
